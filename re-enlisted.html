A modernization project for Starship Troopers (2005), focused on improving compatibility, visuals and presentation while preserving the identity and atmosphere of the original game.

01 // ABOUT THE PROJECT

The war isn't over.

Starship Troopers: Re-Enlisted is an independent modernization project for the original 2005 PC game. The goal is to make the game more comfortable to play on modern Windows systems while improving its presentation without turning it into a completely different experience.

02 // FEATURES

Modernized. Not replaced.
